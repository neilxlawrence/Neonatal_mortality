This code is for use in R to provide the analysis that contributed to the manuscript "Using the National Neonatal Audit Programme (NNAP) to assess the relationship between quality of perinatal care with neonatal mortality and morbidity across the UK"
Authors: K Harris, NR Lawrence, O Adeleye, SJ Clark 

MBRRACE data is downloaded from csv through the online data viewer tool:
https://timms.le.ac.uk/mbrrace-uk-perinatal-mortality/data-viewer/

Download the csv files for total mortality and place them in a folder named "MBRRACE_raw_data/total_mortality" in your working directory

NNAP data is downloaded 
https://www.rcpch.ac.uk/work-we-do/clinical-audits/nnap/data-access

Place NNAP csv files in a folder named "NNAP_raw_data" in your working directory

Ensure the following files are downloaded from the main github page and placed into the correct directory within your working directory:
"manual_unit_level_definition/NNAP_manual_unit_levels_to_add.csv"
"Linking_hospitals_to/hospital_trust_manual_linkage_sheet_master.csv"
"abbreviations_to_load/Abbreviations_to_load.csv"
